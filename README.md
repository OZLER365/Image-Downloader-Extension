# Universal Image Downloader

An advanced browser extension built to extract, filter, and batch-download high-resolution media from complex web pages. Engineered with background network interception and canvas-reconstruction technology, it captures heavily protected images that standard tools miss.

## ✨ Core Features

* **Triple-Engine Extraction:** Switch between Default, Network, and Scrapper (Blob) modes to isolate and capture protected media.
* **Automated De-scrambling:** Detects fragmented or canvas-protected CDN files and seamlessly rebuilds them into pristine, full-resolution pictures.
* **Precision Filtering:** A responsive settings panel allows you to exclude unwanted icons or thumbnails by exact pixel width and height.
* **Versatile Exporting:** Download your curated selection as a single compressed ZIP archive, or queue them individually to a custom folder.
* **Cross-Browser Support:** Fully functional on Firefox, Microsoft Edge, and all Chromium-based browsers (Chrome, Opera, Brave, Vivaldi) including Android mobile environments.

## 🚀 Installation Guide

### Official Add-on Stores
For automatic updates and a seamless experience, install the official release for your primary browser:
* **Firefox:** [Download on Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/universal-image-downloader/)
* **Microsoft Edge:** [Download on Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/universal-image-downloade/dmendeegjofenpfmgfipnnalebefonhd)
* **Userscript Version:** [Available on Greasyfork](https://greasyfork.org/en/scripts/561884-universal-image-downloader)

### Unofficial Chromium Installation (Developer Mode)
To use this extension on Google Chrome, Opera, Brave, or Vivaldi, you can manually install it via Developer Mode:
1. Download the extension's source code as a ZIP file and extract it to a permanent folder on your computer.
2. Open your Chromium browser and navigate to the extensions management page (type `chrome://extensions/` into the URL bar).
3. Toggle the **Developer mode** switch (located in the top-right corner) to the ON position.
4. Click the **Load unpacked** button that appears in the top-left.
5. Select the extracted folder containing the extension files. The extension will instantly install and appear in your browser toolbar.
